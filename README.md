# TNK Emissor — guia de integração

Página pública do guia de integração da API de emissão de NF-e do **TNK Emissor**
(GitHub Pages deste repositório), para os ERPs de parceiros.

Só o contrato da API: rotas, campos, retorno e homologação. Nenhum código, chave,
endereço de servidor ou dado de cliente vem para cá. Os exemplos usam o CNPJ
fictício 11.222.333/0001-81.

## Como atualizar

A página **não se edita aqui**: ela é gerada pela TNK a partir do guia interno,
que confere antes de gerar que não há IP, caminho de disco, CNPJ real ou chave de
NF-e real. Gere de novo e publique o `index.html` resultante.
